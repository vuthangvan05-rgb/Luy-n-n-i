# Luyện Nói Hằng Ngày

App luyện nói tiếng Anh cá nhân, cài được lên điện thoại và học khi không có mạng.

- Thẻ nhớ lặp lại ngắt quãng (kiểu Anki), 56 mẫu câu giao tiếp theo 7 chủ đề
- Luyện phát âm, nói đuổi (shadowing) với gợi ý cho người Việt
- Hội thoại nhập vai theo 8 tình huống
- Chuỗi ngày học, XP, thống kê tiến độ

Cài đặt: mở trang GitHub Pages của repo này trên điện thoại, rồi chọn "Thêm vào màn hình chính".
